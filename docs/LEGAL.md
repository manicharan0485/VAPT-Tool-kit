# Legal Usage Guidelines

## Authorized Use Only

This toolkit is provided for **authorized security testing only**.

## Legal Framework

Use of these tools against systems without explicit written authorization is illegal under:

- **Germany**: §202a, §202b, §202c StGB (Strafgesetzbuch) — Unauthorized data access, data interception, and possession of hacking tools can result in fines or imprisonment up to 3 years.
- **EU**: Directive on attacks against information systems (2013/40/EU)
- **United States**: Computer Fraud and Abuse Act (CFAA) — 18 U.S.C. § 1030
- **United Kingdom**: Computer Misuse Act 1990
- **International**: Budapest Convention on Cybercrime

## Before You Test

1. ✅ Obtain **written authorization** from the system owner
2. ✅ Define the **scope** clearly (IP ranges, domains, test windows)
3. ✅ Agree on **rules of engagement** (what's in/out of scope)
4. ✅ Have **emergency contacts** ready (in case of unintended disruption)
5. ✅ **Document everything** before, during, and after

## Responsible Disclosure

If you discover vulnerabilities during authorized testing:

1. Document the finding thoroughly
2. Report to the organization within agreed timelines
3. Allow reasonable time to remediate before any disclosure
4. Follow coordinated disclosure practices
